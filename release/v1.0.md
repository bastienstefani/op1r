# op1r v1.0 — OP-1 R246 custom firmware patcher

Turns the original OP-1 firmware **R246** (`op1_246.op1`, not included) into a custom firmware.
Requires Python 3.8+ only.

```sh
python3 patch_op1.py /path/to/op1_246.op1     # -> op1_246-custom.op1
```

Flash the result like any OP-1 update (bootloader update mode). The original firmware can always be flashed back.
**Use at your own risk.**

## What's in it
- Synth engines with their own screens: **supersaw**, **fmbell**, **granular**
- FX with their own screens, usable on instruments and as master FX: **tape** echo, **clouds** granular
- **quad** LFO: four LFOs per slot for synths and drums, targeting engine knobs, envelope or FX, per voice or
  free-running
- Hidden **OP-Z controller mode** (COM → CTRL, SysEx `F0 00 20 76 00 01 03 F7`)

## New since the last push
- Quad LFO now modulates drum engine knobs and drum FX.
